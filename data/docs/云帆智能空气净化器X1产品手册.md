# 云帆智能空气净化器 X1 产品手册

## 产品概述

云帆智能空气净化器 X1（以下简称 X1）是云帆科技（YunFan Tech）于 2025 年 3 月发布的旗舰级家用空气净化器。X1 采用双层塔式结构，颗粒物 CADR 值为 400 m³/h，甲醛 CADR 值为 220 m³/h，适用于 28 至 48 平方米的房间。整机尺寸为 350 × 350 × 638 毫米，净重 7.8 千克，提供象牙白与曜石黑两种配色，官方零售价 1499 元。

## 核心参数

| 项目 | 参数 |
| --- | --- |
| 颗粒物 CADR | 400 m³/h |
| 甲醛 CADR | 220 m³/h |
| 适用面积 | 28 - 48 ㎡ |
| 噪音范围 | 32 - 54 dB(A) |
| 额定功率 | 4.5 - 38 W |
| 待机功率 | ≤ 1.5 W |
| 滤芯类型 | H13 级 HEPA + 高碘值活性炭复合滤芯 |
| 无线连接 | Wi-Fi 2.4GHz，支持云帆智联 App |
| 尺寸 | 350 × 350 × 638 mm |
| 净重 | 7.8 kg |

## 滤芯与耗材

X1 使用复合滤芯（型号 YF-F2），集成 H13 级 HEPA 滤网与高碘值改性活性炭。在每日使用 8 小时的标准工况下，建议每 6 至 12 个月更换一次滤芯；若长期处于高污染环境（如装修期），建议缩短至 3 个月。官方滤芯单价为 199 元，可在云帆商城或授权渠道购买。App 会在滤芯寿命不足 10% 时推送提醒，更换新滤芯后需在 App 中执行"滤芯复位"操作。

## 保修政策

X1 整机保修 2 年，电机部件保修 5 年，滤芯属于耗材不在保修范围内。保修期自购买之日起计算，需提供有效购买凭证。人为损坏、未按说明书使用导致的故障不在免费保修范围内。保修期内维修产生的往返物流费用由云帆科技承担。

## 使用注意

1. 请勿在浴室等高湿度环境中使用，相对湿度上限为 85%。
2. 进风口位于机身两侧，摆放时请与墙壁保持至少 30 厘米距离。
3. 长期不使用时，请拔掉电源并将滤芯取出密封保存，避免活性炭受潮。
4. 机器运行时若出现异味或异响，请立即断电并联系客服热线 400-880-6666。
